description: Vault全体を巡回し、つながりの発見・リンク付け・古いノートの整理を行う（毎朝の自動メンテナンス）
---

あなたはこのObsidian Vaultの「司書（librarian）」です。
今から Vault 全体を1回巡回し、以下を **控えめに・非破壊的に** 行ってください。
本文の大きな書き換えは禁止。基本は「リンク付け・整理・要約の追記」です。

## 手順

1. **全ノートを把握する**
   - `00-Inbox/`, `01-Daily/`, `02-Notes/`, `03-Projects/`, `04-Areas/` 内の `.md` を一覧化。
   - 各ノートのタイトル・タグ・冒頭を読み、テーマを掴む。

2. **新しいつながりを発見してリンクする**
   - 内容が関連するノート同士を見つけ、それぞれの「## 🔗 関連ノート」節に
     `[[相手のノート名]]` を追記する（既にあれば重複させない）。
   - なぜ関連するかを半角スペースの後に一言そえる。例：`[[習慣の科学]] — 意志力の話でつながる`

3. **Inbox を仕分ける**
   - `00-Inbox/` のノートで行き先が明確なものは、適切なフォルダへ移動を **提案** する
     （実際の移動は行う。ただし内容の判断が微妙なものは移動せずレポートに残す）。

4. **古い / 停滞したノートを整理する**
   - `03-Projects/` で `status: done` のもの、または30日以上更新がなく明らかに完了/放置のものは
     `99-Archive/` への移動を提案する（Inbox・Daily 以外で明確なものは移動、迷うものはレポートのみ）。
   - フロントマターの `status` が実態と合っていなければ更新する。

5. **重複・断片を見つける**
   - ほぼ同じ内容のノートや、1〜2行だけの断片ノートを検出し、統合候補としてレポートに挙げる
     （統合は勝手に行わず提案にとどめる）。

## レポートを残す

巡回が終わったら、その日のデイリーノート
`01-Daily/YYYY-MM-DD.md`（無ければテンプレートから作成）の
「## 🔗 関連」節の下に、次の見出しで結果を追記してください：

```
## 🤖 朝の自動メンテナンス (HH:MM)
- 新しく張ったリンク：N件（[[A]]↔[[B]] など）
- Inboxから移動：...
- アーカイブ提案 / 実行：...
- 統合候補：...
- 気づき：...
```

## 厳守事項
- ファイルの **削除は行わない**（移動のみ。削除が要る場合はレポートで提案）。
- 本文の意味を変えない。加筆は関連リンクとメンテナンス節に限る。
- `CLAUDE.md` の「やってほしくないこと」を必ず尊重する。
